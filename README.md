# المنصة الجغرافية المرجعية V2.3 — برنامج سطح المكتب (Windows)

برنامج Electron يفتح المنصة المشتركة في نافذة خاصة. البيانات والدخول بالكود من خادم المنصة نفسه،
فما يراه مستخدم البرنامج هو ما يراه مستخدم المتصفح. **يحتاج اتصالاً بالإنترنت.**

عنوان المنصة مثبّت في `main.js` (`PLATFORM_URL`). إن تغيّر الرابط فعدّله هناك وفي `app/offline.html` ثم أعد البناء.

## البناء

```bash
npm install
npm start          # تشغيل للتجربة
npm run dist:win   # بناء ملفات ويندوز في مجلد dist/
```

كل تحديث يُرفع إلى هذا الفرع يبنيه GitHub Actions تلقائياً، والناتج في Artifacts باسم `Taif-Geo-Platform-Windows`:
- `Taif-Geo-Platform-Setup-<version>.exe` — مثبّت
- `Taif-Geo-Platform-Portable-<version>.exe` — نسخة محمولة

تحديثات المنصة نفسها (لوحات، بيانات، صلاحيات) تصل للبرنامج تلقائياً دون إعادة تثبيت، لأنه يعرض النسخة المنشورة.
