# المنصة الجغرافية المرجعية V2.3 — النسخة المشتركة

نسخة مستقلة من المنصة تعمل على خادمك: قاعدة بيانات واحدة يراها كل المستخدمين، والدخول بكود ينشئه المدير.

## ما الذي تحتويه

| المسار | الغرض |
|---|---|
| `/` | المنصة نفسها (تطلب كود الدخول) |
| `/login` | صفحة إدخال الكود |
| `/admin` | لوحة المدير: إنشاء الأكواد، الصلاحيات، المدة، الإقفال، الأجهزة، سجل الدخول، نسخة احتياطية |

## الصلاحيات

| الدور | قراءة | رفع تقارير Excel | تحديثات ومخاطر ونطاقات وصور | توجيهات القيادة | أرشفة التقارير التنفيذية |
|---|---|---|---|---|---|
| مشاهد | ✓ | | | | |
| مدخل البيانات | ✓ | ✓ | ✓ | | |
| مدير PMO | ✓ | ✓ | ✓ | ✓ | ✓ |
| الرئيس التنفيذي | ✓ | | | ✓ | |

الصلاحيات تُفرض في الخادم (`server/perms.js`)، لا في الواجهة فقط.

## التشغيل على جهازك للتجربة

يحتاج Node.js 22.13 أو أحدث.

```bash
npm install
ADMIN_PASSWORD="كلمة-مرور-قوية" npm start
```

ثم افتح `http://localhost:3000/admin` وأنشئ أول كود.

## الإعدادات (متغيرات البيئة)

| المتغير | الغرض |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة المدير. **إلزامية في النشر**؛ اختر كلمة طويلة لا تُخمَّن |
| `DATA_DIR` | مجلد قاعدة البيانات والملفات المرفوعة (الافتراضي `./data`، وفي Docker `/data`) |
| `PORT` | المنفذ (الافتراضي 3000) |

## النشر على استضافة سحابية

المستودع فيه `Dockerfile` جاهز. في أي منصة تدعم Docker وقرصاً دائماً (مثل Railway أو Fly.io أو Render):

1. أنشئ خدمة جديدة من هذا المستودع (فرع `shared-platform`). المنصة تكتشف `Dockerfile` وتبني منه.
2. أضف قرصاً دائماً (Volume) واربطه بالمسار `/data`. **بدونه تُمسح البيانات والأكواد عند كل إعادة تشغيل.**
3. أضف المتغير `ADMIN_PASSWORD`.
4. فعّل الرابط العام (HTTPS). الرابط هو ما ترسله للمستخدمين مع أكوادهم.

للنقل لاحقاً إلى خادم داخلي: الحزمة نفسها تعمل بالأمر
`docker run -d -p 80:3000 -v /path/to/data:/data -e ADMIN_PASSWORD=... <image>`، وتنقل معها مجلد `/data`.

## النسخ الاحتياطي

- من لوحة المدير: زر «نسخة احتياطية» ينزّل بيانات المنصة ملف JSON (بلا أكواد الدخول).
- النسخة الكاملة: مجلد `DATA_DIR` كله (ملف `platform.db` ومجلد `assets`).

## تحديث المنصة إلى إصدار جديد

1. نزّل ملف HTML للإصدار الجديد من claude.ai.
2. شغّل `node scripts/build-app.mjs <الملف>`؛ يكتب `web/app.html` بعد ربطه بالخادم.
   إن تغيّر كود المنصة في مواضع الربط يتوقف السكربت برسالة تحدد الموضع.
3. ارفع التغيير إلى المستودع فتُعاد النشر.

## ملاحظات أمنية

- الأكواد تُحفظ مشفّرة (hash) ولا يمكن استرجاعها؛ إن ضاع كود فاستخدم «إعادة توليد».
- حد الأجهزة يعتمد على معرّف يُحفظ في المتصفح، فمسح بيانات المتصفح يجعل الجهاز يُحسب جهازاً جديداً.
- عشر محاولات دخول فاشلة من العنوان نفسه توقفه ربع ساعة.
